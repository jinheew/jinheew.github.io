Adding a new post

Copy this file to blog/your-slug.html, change the <title>, heading, and date, and write the body. Then add a row to the Blog table on the homepage, newest first: 

<tr>
  <td style="padding:8px 16px;width:20%;vertical-align:top;color:#888;white-space:nowrap">
    Sep 2, 2026
  </td>
  <td style="padding:8px;width:80%;vertical-align:top">
    <a href="blog/your-slug.html">
      <span class="papertitle">Your title</span>
    </a>
    <br>
    A one-line summary.
  </td>
</tr>
